# TWIN SOLS: ECHO COUNCIL

Static HTML5 prototype for the 2026 NASA Space Apps Challenge.

## Run locally

Serve `dist/` with any static server, for example:

```powershell
python -m http.server 4173 --directory dist
```

Then open `http://localhost:4173`.

## Prototype systems

- 10-sol mission with branching choices and computed endings
- Power, life support, and radiation safety resources
- Greenhouse, communications, shelter, and rover modules
- Crew health, fatigue, trust, pair relationships, promises, and memory flags
- Delayed consequences through the Echo Queue
- Science result, future-choice gating, and hidden story flags
- Visual-novel dialogue, procedural text blips, consequence cutscenes, and cause map
- Clearly labeled archived NASA/partner-agency data cards

## Data references

- NASA DONKI
- NASA OSDR / RadLab
- NASA Mars Trek
- Canadian Space Agency food-production education toolkit

The prototype transforms real archived data into an educational scenario and does not present itself as an operational forecast.
